# Text to Code Voice Sim

This example simulates the core concept of "voice coding" discussed in the article. It takes natural language text commands (representing spoken input) and translates them into basic Python code snippets. This demonstrates how code can be generated without traditional keyboard typing, aiming to replace the manual "write-wait-check" cycle.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Enter commands like "define function greet_user" or "print variable my_var" and observe the generated Python code.
